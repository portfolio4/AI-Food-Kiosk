Below that is a text box, that we'll call the "conversation box".

Below that is a "record" button that the user clicks when they're ready to start ordering by speaking into a microphone. As the user speaks, the words they speak will be typed out into the conversation box. You don't have to implement the speech-to-text functionality, just mock it out with some dummy text.

When the user clicks the "record" button, it turns into a "stop record" button with a red box. Once the user is done speaking, they click the "stop record" button.

Then the response from the server backend should display in the conversation box. You can stub out the server response for now.
