High level requirements:

- We are building a AI restaurant kiosk app.
- The user speaks into the kiosk to ask questions about the menu and place an order.
- The frontend sends the audio to the backend using webrtc.
- The backend processes the audio bytes and uses a Codex session to generate a response to the frontend.
- The frontend speaks the response back to the user.

------------------

What we've already built:

We've built the Rust web-rtc server at backend/simple_rtc.

We've built the web-rtc frontend client at frontend/js/webrtc.js

We've built a UI with menu and record button for speaking to the AI agent at frontend/kiosk.html

We've gotten the frontend to stream live audio encoded in Opus format to the
rust backend via AudioTrack.

We've coded the backend to decode the audio bytes from the frontend and convert
to text.

We've gotten the backend to send the decoded audio bytes back to the
frontend to display to the user.

-------------------

What to build next:

We need the AI to respond to the user's requests.

In the rust backend, we will create an agent crate.
The agent create will have an CodexAgent class.
CodexAgent constructor will spawn a private codex CLI session.
CodexAgent will also provide a function prompt() that takes the String prompt
and takes a callback that will be invoked with the String response from the agent
once the agent is done.

In backend/src/main.rs , instantiate a CodexAgent.
Then, whenever we have committed_text and are about to print it,
we also send that committed_text as a prompt to the CodexAgent.
When we get the response back from the CodexAgent,
we take the result and send back to the frontend:
{"msg_type": "ai_response", "text": <response from agent>}

On the frontend, whenever we get an ai_response, we should append it to
the Order Conversation window but label it as from the "Assistant" side.
Note that if there is currently a pulsing text bubble due to the user
being in midspeech, we should put the assistant's response above the pulsing
text bubble, so that the pulsing text bubble is always at the bottom.
